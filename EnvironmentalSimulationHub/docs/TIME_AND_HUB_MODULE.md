# Unified Hub and native time tools — 0.7.2

`EnvironmentalHub` now opens the workflow overview. `EnvironmentalRadiation` opens the previous radiation panel directly. Other direct commands remain: EnvironmentalWeather, EnvironmentalLocation, EnvironmentalClimate; EnvironmentalTime is new. All modules share a compact selector/Open navigation, title/description hierarchy, readable hints and spacing tokens. The overview has five actual module entry points, not mock analysis dashboards. Existing registered panels retain their own inputs/results; no new state-sharing or implicit transfer of climate/time inputs is claimed.

The Time Panel provides three original functions: LB Analysis Period, LB Calculate HOY and LB HOY to DateTime. Period requests specify start/end month/day/hour and one of the original steps/hour: 1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60. The adapter returns native period JSON, every fractional HOY and aligned month/day/hour/minute entries. Cross-year ordering, overnight selection, timestep endpoints and native end-day normalization are preserved. The Panel explicitly notes a normalized end day rather than silently presenting it as the requested value.

Calendar requests convert a non-leap date/minute to HOY/DOY or a single fractional HOY back to native DateTime. HOY is zero-based, DOY one-based, local standard time; no civil-zone/DST conversion. Leap dates are blocked. Invalid requests and original GH errors preserve prior results. Export stores full typed values, parameters, original component/version/hash and time convention. EPW and radiation contracts still accept integer-hour selection; this release does not automatically feed fractional time steps into hourly EPW.
