匯入格式說明

必填欄位：

  • 題目內容
  • 題目類型（單選/多選/是非）
  • 正確答案
  • 難度（S/A/B/C）

選填欄位：

  • 選項A、選項B、選項C、選項D
  • 答案解析
  • 標籤（多個用逗號分隔）
  • 相關技能
  • 啟用（Y/N，預設 Y）

答案格式：

  • 單選：A 或 B 或 C 或 D
  • 多選：A,B,C 或 A;B;C
  • 是非：TRUE 或 FALSE
