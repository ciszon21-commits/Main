# SiteANA — 使用者操作指南

**版本**: v0.6.0-alpha | **最後更新**: 2026-03-31

> SiteANA 是專為建築師設計的 Web GIS 基地分析工具，支援地圖底圖切換、基地繪製、空間分析（面積/坪數/周長/緩衝區）以及高品質 PDF/PNG 出圖。

## 系統啟動

雙擊專案根目錄的 **`SiteANA-一鍵啟動.bat`** 即可自動啟動前後端服務。

啟動成功後，瀏覽器將自動開啟：
- **前端介面**：http://127.0.0.1:5173
- **後端 API 文件 (Swagger)**：http://127.0.0.1:8000/docs

> [!NOTE]
> 若系統環境未安裝 Docker，後端空間分析將以 **Turf.js 模擬模式**在瀏覽器中執行，所有功能仍可正常使用。

## 介面說明

介面分為兩個主要區域：

| 區域 | 說明 |
|:---|:---|
| **左側邊欄** | 專案/基地管理、空間分析、出圖設定、底圖樣式切換 |
| **地圖主畫面** | 互動底圖，支援縮放、平移、繪製與標記 |

- **收合側邊欄**：點擊側邊欄標題列右側的 `◀` 圖示。
- **展開側邊欄**：點擊地圖左上方的浮動 `▶` 按鈕。

## 尋找基地

在地圖頂部中央的搜尋框中輸入**地址或地標名稱**（中文或英文皆可），系統將透過 OSM Nominatim API 進行地址解析。

**操作步驟：**
1. 在搜尋框輸入（例如：「台北市政府」或「中正紀念堂」）
2. 稍待 0.5 秒後，下方出現搜尋結果清單
3. 點選目標地址，地圖自動飛移至該位置

> [!WARNING]
> 若公司內部網路封鎖了對外連線，搜尋功能將顯示錯誤提示。此時請直接在地圖上手動定位並開始繪製。

## 繪製基地輪廓

地圖左側的**繪製工具**面板（浮動在地圖上）提供手繪與匯入功能。

### 手動繪製

1. 點擊「**開始繪製基地**」按鈕
2. 在地圖上依序**點選基地角點**（每次點擊設定一個節點）
3. 至少 3 個點後，點擊「**完成繪製 (N 點)**」
4. 藍色半透明多邊形出現在地圖上，表示基地已記錄完成

### 匯入 GeoJSON

- 點擊「**匯入 GeoJSON**」，選擇本地的 `.geojson` 或 `.json` 檔案
- 系統自動解析並將基地範圍顯示於地圖
- 地圖視角自動縮放至基地範圍

### 匯出 GeoJSON

- 繪製完成後，點擊「**匯出 GeoJSON**」可下載標準格式的地理資料檔案
- 可用於匯入至 QGIS、ArcGIS、Rhino 等專業軟體

## 空間分析

側邊欄的 **Spatial Analysis** 面板在繪製基地後才會啟用。

### 計算面積與周長

1. 完成基地繪製後，點擊「**計算基地面積與周長**」
2. 系統顯示：
   - **面積**: 平方公尺 (m²) 及坪數
   - **周長**: 公尺 (m)
   - **重心座標**: 緯度/經度

### 緩衝區分析

1. 在「緩衝半徑 (m)」欄位輸入距離（例如：50）
2. 點擊「**套用緩衝**」
3. 地圖上出現**橘色虛線緩衝圈**，代表從基地邊界向外擴展的影響範圍

## 底圖與外觀切換

### 底圖樣式（Style Presets）

側邊欄下方的 **Style Presets** 區塊提供 5 種底圖選擇：

| 樣式名稱 | 適合用途 |
|:---|:---|
| Liberty (Default) | 一般分析、細節豐富 |
| OSM Raster (Fallback) | 網路受限時的備用底圖 |
| Bright Mode | 明亮簡潔，適合簡報 |
| Minimal Dark | 深色模式，適合夜間工作 |
| Blueprint Mode | 藍圖風格 |

### 分析圖模板（Templates）

- **簡報預覽 (16:9)**：適合投影機或簡報展示
- **圖紙預覽 (A3/A4)**：配合列印排版

### 顏色與字體主題（Appearance）

在 **Appearance** 區塊可以切換：
- **顏色主題**：Brand（藍）/ Slate（灰）/ Emerald（綠）
- **字體**：Sans（無襯線）/ Serif（有襯線）/ Mono（等寬）

## 出圖匯出

側邊欄的 **Export** 面板提供一鍵出圖功能，截取目前地圖視窗範圍。

### 設定說明

| 設定 | 選項 | 說明 |
|:---|:---|:---|
| **格式** | PDF / PNG | PDF 包含標題列、日期、分析數據頁尾 |
| **解析度** | Standard / High | High = 2x 像素密度，適合印刷 |

### 操作步驟

1. 選擇匯出**格式**（PDF 建議用於正式出圖）
2. 選擇**解析度**（High 适合 A3 印刷）
3. 確認地圖已調整到想要的視角
4. 點擊「**匯出 PDF / PNG**」
5. 約 5–10 秒後檔案自動下載

> [!TIP]
> **PDF 匯出特性**：
> - 頁首含藍色品牌列、專案名稱、出圖日期
> - 頁尾含面積/周長統計數據（若已分析）、紙張尺寸、SiteANA 品牌標記
> - 紙張尺寸依選擇的「分析圖模板」自動切換（簡報 = A3 橫，圖紙 = A4 橫）

## 常見問題

### ❓ 地圖顯示空白

**原因**：連線至 OpenFreeMap 向量底圖失敗（公司網路限制）

**解法**：在側邊欄的 Style Presets 切換至「**OSM Raster (Fallback)**」

---

### ❓ 地址搜尋沒有反應

**原因**：Nominatim API (`nominatim.openstreetmap.org`) 可能被防火牆封鎖

**解法**：直接在地圖上平移定位，或請 IT 人員協助開放對外 HTTPS 連線

---

### ❓ 匯出 PDF 出現亂碼

**原因**：jsPDF 不支援部分中文字體

**解法**：頁首/尾為英文標記，地圖截圖部分仍為正確畫面。若需要完整中文標題，可於匯出後使用 Acrobat 編輯 PDF 加入文字。

---

### ❓ 空間分析的面積數值看起來不對

**原因**：若後端未啟動，使用 Turf.js 前端計算，精度稍低（差異 < 1%）

**解法**：啟動後端服務（uvicorn）後，數值將改由 Shapely + pyproj 計算，精度更高
