CoDev Studio

Collaborative Development / Code Vibe Studio

公開給所有公司同仁，相關設定已齊備，適合 Vibe Coding 後由研資部檢核上線。全面開放的協作開發平台，讓創新觸手可及。

核心特色
全員開放 專屬課程 專業審查 快速上線

開發流程

1

註冊與 Fork

前往 Gitea 伺服器 註冊帳號，並 Fork 專案到個人空間

2

Clone & Git Flow

Clone 您的 Fork，設定 Upstream，並使用 Git Flow 建立功能分支進行開發

3

開始 Vibe Coding

使用向 AI 許願，使用各種 Vibe Coding 功能，開始進行開發

4

提交 Pull Request

推送分支到您的 Fork，並在 Gitea 上建立 Pull Request (PR) 請求合併

5

審查與上線

通過 Code Review 與資安審查後，合併至主分支並部署上線
