開發流程

1

註冊與 Fork

前往 Gitea 伺服器 註冊帳號，並 Fork 專案到個人空間

2

Clone & Git Flow

Clone 您的 Fork，設定 Upstream，並使用 Git Flow 建立功能分支進行開發

3

提交 Pull Request

推送分支到您的 Fork，並在 Gitea 上建立 Pull Request (PR) 請求合併

4

審查與上線

通過 Code Review 與資安審查後，合併至主分支並部署上線
